# AS Aircon Service Website

Next.js marketing website for **AS Aircon Service** (AS Appliance Services LTD) with Home, About Us, and Contact Us pages, matching the provided design mockups and SEO best practices.

## Pages

- `/` — Home (hero, services, SEO guide, FAQ, why choose us, testimonials, contact form)
- `/about-us` — About Us
- `/contact-us` — Contact Us

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## SEO Included

- Unique metadata titles & descriptions per page
- Open Graph / Twitter cards
- `sitemap.xml` and `robots.txt`
- JSON-LD `HVACBusiness` schema
- Semantic HTML landmarks and heading hierarchy
